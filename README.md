# Zpěvník 🎵

Projekt sbírky písní v LaTeX formátu.

## Struktura projektu

### Hlavní soubory
- **zpevnik_elektronicky.tex** - Elektronická verze zpěvníku
- **zpevnik_nastroj.tex** - Verze zpěvníku zaměřená na rychlé čtení jedné písničky
- **zpevnik_papirovy.tex** - Verze zpěvníku optimalizovaná pro tisk

### Složky
- **songs/** - Kolekce jednotlivých písní v .tex formátu, seřazené alfabeticky
- **nové_písničky/** - Nové písně po sdileni všem skautum na Overleaf
- **images/** - Obrázky a doplňující materiál

### Pomocné soubory
- **guitar.sty** - Vlastní LaTeX styl pro formátování
- **_jak psát novou písničku - pro všechny.txt** - Návod pro přidávání nových písní

## Listy písní
V složce `songs/` jsou dostupné seznamy pro specifické sbírky:
- _seznam_hunger_games_javo.txt
- _seznam_javoricko_2022.txt
- _seznam_pisarov_24.txt
- _seznam_lu_2024.txt
- A další...

## Použití
1. Upravte obsah v jednotlivých .tex souborech
2. Kompilujte LaTeX dokumenty do PDF
3. Nové písně přidávejte do složky `songs/` a aktualizujte příslušné seznamy
